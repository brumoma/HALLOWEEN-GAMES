⚡ Grammar Rules (A2)

1. Present Simple (Routines vs. He/She):

• I / You / We / They ➔ fly, wear, eat

• He / She / It ➔ flies, wears, eats (+s/es!)

Example: A witch flies on a broomstick.

2. Like / Don't Like:

• He / She ➔ likes / doesn't like

Example: The vampire doesn't like garlic or sunlight!

3. There is / There are:

• There is + Singular (e.g. There is a ghost in the room.)

• There are + Plural (e.g. There are three bats in the tree.)

4. Frequency Adverbs:

• Placed before main verbs: Witches usually make potions.

• Placed after verb TO BE: Monsters are always scary.
